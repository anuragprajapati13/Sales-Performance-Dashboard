# 📊 Sales Analysis Dashboard | Power BI

An interactive **Sales Analysis Dashboard** built using Microsoft Power BI to analyze business performance, sales trends, profitability, and product performance across different regions, customer segments, and shipping modes.

The dashboard transforms raw sales data into meaningful visual insights, helping businesses understand their performance and make data-driven decisions.

## 🚀 Project Overview

The Sales Analysis Dashboard provides a comprehensive overview of business sales performance from **2014 to 2017**.

It allows users to explore key business metrics and identify trends through interactive visualizations and filters.

The dashboard focuses on understanding:
- Overall sales and profit performance.
- Sales distribution across different product categories.
- Regional sales performance.
- Monthly and quarterly sales trends.
- Customer segment contribution.
- Shipping mode distribution.
- Top-performing products.

## 🎯 Project Objectives

- Analyze overall sales and profitability.
- Identify the most profitable product categories.
- Compare sales performance across different regions.
- Understand monthly and quarterly sales patterns.
- Analyze customer segments and shipping preferences.
- Identify top-performing products based on sales.
- Present business insights through an interactive dashboard.

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)
Displays important business metrics:
- Total Sales
- Total Profit
- Total Quantity Sold
- Total Discount

### 2. Regional Sales Analysis
- Analyzes sales across Central, South, East, and West regions.
- Helps compare regional business performance.

### 3. Category-Wise Sales Analysis
- Technology
- Furniture
- Office Supplies

Visualizes sales contribution from each product category.

### 4. Monthly Sales Analysis
- Tracks monthly sales performance.
- Identifies high-performing and low-performing months.
- Helps understand seasonal sales trends.

### 5. Sales by Shipping Mode
Analyzes sales distribution across:
- Standard Class
- Second Class
- First Class

### 6. Customer Segment Analysis
Compares sales contribution across:
- Consumer
- Corporate
- Home Office

### 7. Quarterly Sales Analysis
Provides a comparison of sales across Q1, Q2, Q3, and Q4.

### 8. Product Performance Analysis
Displays the top 10 products based on sales value to identify important revenue-generating products.

### 9. Profitability Analysis
Visualizes profit contribution across different product categories and examines the relationship between sales and profit.

Users can explore the dashboard using:
- Year filters (2014, 2015, 2016, 2017)
- Region filters (Central, South, East, West)

These filters allow users to analyze business performance for specific years and geographical regions.

2. Which geographical region performs better.
3. Which customer segment generates the most revenue.
4. Which shipping mode contributes the largest sales share.
5. How sales fluctuate throughout the year.
6. Which products generate the highest sales.

## ⚙️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Sales-Analysis-Dashboard
   ```

3. Download and install Microsoft Power BI Desktop.

4. Open the `.pbix` file using Power BI Desktop.

5. If required, update the dataset source path.

6. Click **Refresh** to load the data.

7. Explore the dashboard using the available filters and visualizations.
